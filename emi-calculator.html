The formulaफ़ॉर्मूला

EMI = P x r x (1 + r) ^ n / ((1 + r) ^ n - 1), with r the monthly rate and n the months.EMI = P x r x (1 + r) ^ n / ((1 + r) ^ n - 1), जहाँ r मासिक दर और n महीने हैं।
